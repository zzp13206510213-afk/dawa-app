# 数字大外 · 手机端 App（可安装 / 离线可用）

把学校的活动通知聚合到一起，让每个同学都能收到、都能参与。四个界面（首页兴趣论坛 / 主界面数字大外 / 活动详情报名互动 / 我的个人中心）都是真界面、可点击、可交互。

## 怎么在手机上运行

### 方式 A：只想快速看一眼（最简单）

1. 把文件 `数字大外-手机版.html`（在 outputs 目录里）通过 AirDrop / 微信 / 邮件 / 云盘 发到手机；
2. 在手机上用浏览器打开这个文件（iOS 用「文件」App 点开选 Safari；Android 用 Chrome 打开）；
3. 直接就能用。这种方式不需要联网，也不需要装任何东西。

> 注意：部分手机浏览器打开本地文件时不允许存数据，这种情况下点赞 / 报名记录在关掉页面后会重置，其余交互正常。

### 方式 B：装到手机主屏（推荐，像原生 App 一样）

1. 电脑和手机连同一个 WiFi；
2. 在这个 `dawa-app` 文件夹里启动一个本地服务器：

   ```bash
   cd outputs/dawa-app
   python3 -m http.server 8080
   ```

3. 查一下电脑的局域网 IP（Mac：`ipconfig getifaddr en0`），例如 `192.168.1.23`；
4. 手机浏览器访问 `http://192.168.1.23:8080`；
5. **iPhone（Safari）**：点底部分享按钮 → 「添加到主屏幕」；
   **Android（Chrome）**：点右上角菜单 → 「安装应用 / 添加到主屏幕」。

装好后主屏会出现「外」字图标，点开是全屏无浏览器地址栏的独立 App，断网也能打开（Service Worker 已缓存全部页面）。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 整个 App（样式、逻辑、数据都在里面，无外部依赖） |
| `manifest.webmanifest` | 安装到主屏所需的配置（名称、图标、全屏显示） |
| `sw.js` | 离线缓存，装到主屏后断网可用 |
| `icons/*.png` | 主屏图标（192 / 512 / maskable / Apple Touch） |

> 布局小提示：`#viewport` 负责裁剪、`#screens` 负责横向滑动（四个标签页排在一条轨道上），所以新增标签页时只要往 `TABS` 里加一项即可，轨道和底部高亮块会自动适配。

## 已经实现的交互

- **底部导航栏（Instagram 悬浮胶囊风格）**：悬浮在内容之上、圆角胶囊外形、毛玻璃底；纯图标无文字，选中项变成实心图标，并且高亮块会**从上一个标签平滑滑到新标签**；「我的」直接显示你的头像（选中时落在高亮块上并套一圈品牌色描边），未读消息在图标右上角显示红点并脉冲一下。
- **左右滑动切换标签**：在任意标签页横向滑动即可切换，内容和高亮块都跟手指走，松手后按滑行距离吸附到上一屏或下一屏；首页边缘有回弹阻尼；滑动时不会误触卡片。
- **过场动画**：打开子页面时当前页向左退一屏、新页面从右侧推入（二级页面继续叠推），返回时反向收回；切换底部标签有方向感的淡入位移 + 图标回弹；首页信息流与活动列表进场时逐条上浮；点赞有心跳回弹、报名成功有光圈闪烁、新评论会高亮一下；底部选择面板、提示条、图片放大都有独立动效。
- **首页**：搜索活动与话题、兴趣板块筛选（书法 / 穿搭 / 摄影 / 绘画 / 手工）、点赞、关注社团、图片放大、帖子分享。
- **发现（活动广场）**：按文体 / 学术 / 讲座 / 志愿筛选，活动卡片直接跳报名。
- **活动详情**：名额进度条实时变化、报名与取消报名、点赞、评论（自己发的评论会排在第一条）、邀请同学、一键转发到班级群文案。
- **应用（主界面）**：八个应用入口、收件箱（未读红点、点开即已读、全部已读）、待办事件（勾选、新建）。
- **我的**：可编辑的个人资料（头像 / 昵称 / 性别 / 出生日期 / 学院 / 专业 / 年级 / 校区 / 手机号 / 邮箱 / 个性签名，带资料完善度与校验）、我的关注、赞收藏、日程表、课表（按每周起始日排布）、图书馆续借、一卡通、成绩查询。
- **语言与地区**：界面语言（简体中文 / English，菜单与设置项即时切换）、时区（跟随系统 / 北京 / 东京 / 伦敦 / 纽约，带实时时间预览）、日期格式（三种，影响课表与日程显示）、货币单位（影响一卡通余额）、每周起始日（影响课表排序）。
- **隐私设置**：动态可见范围（所有人 / 同校同学 / 仅关注 / 仅自己）、允许通过学号找到我（关掉后搜索里真的搜不到）、展示活动参与记录、个性化推荐、允许社团邀请、位置信息、黑名单管理（可移出）、清除浏览记录。
- **通用设置**：深色模式（跟随系统 / 浅色 / 深色）、字体大小（小 / 标准 / 大，全局生效）、极速模式（关掉毛玻璃与阴影）、活动提醒 / 报名截止提醒 / 系统通知、免打扰时间、自动播放动图、清理缓存、检查更新、清除本地数据。
- **账号与安全 / 客服中心 / 关于大外**：安全等级与最近登录、修改密码、校园统一身份认证、登录设备管理、常见问题、用户协议与隐私政策入口。
- **串联逻辑**：报名活动 → 自动加入待办和日程 → 收件箱通知变为已读 → 首页帖子可直达活动；关闭「活动提醒」后收件箱会提示可能错过截止时间；改昵称和头像会同步到评论、报名名单与我的页面。所有操作都会保存在手机本地（localStorage），关掉再打开还在。

## 想改回带文字标签的底部栏

在 `index.html` 里把 `<div id="app">` 改成 `<div id="app" class="show-tab-labels">` 即可，底部会变回「图标 + 文字」的老样式。系统「减弱动态效果」和 App 内的「极速模式」都会自动关掉全部动画。

## 数据说明

所有活动、帖子、通知都是示例数据，写在 `index.html` 的 `ACTS` / `POSTS` / `MAILS` 三个数组里，替换成真实内容即可。清空本地数据：我的 → 通用设置 → 清除本地数据并恢复默认。
